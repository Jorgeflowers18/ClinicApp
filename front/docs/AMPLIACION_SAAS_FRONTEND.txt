IDENTIDAD Y FORMULARIOS DE ACCESO
- Validador y normalización compartidos para usuario o correo.
- Nombre de usuario de 3 a 30 caracteres; comprobación local de duplicados sin
  distinguir mayúsculas, sugerencia y conservación de identificadores internos.
- Nombres y Apellidos se conservan por separado, incluso cuando tienen varias palabras.
- Login real por correo mantiene su contrato email/password/rememberMe.
- Un alias preparado localmente se resuelve al correo real antes del login; la
  contraseña sigue siendo validada por la API existente.
- Solicitar acceso incorpora usuario solicitado como propuesta administrativa local.
  El POST real conserva fullName/email/institution/message.
- Recuperación acepta alias conocido localmente o correo; la confirmación es genérica.
- Restablecimiento real conserva el enlace con token y el endpoint existente.
- Activación, cambio obligatorio y cambio desde Mi perfil tienen recorridos explícitos
  de demostración. No generan tokens, no envían correos y no almacenan contraseñas.
- Primera configuración permite crear usuario o muestra el ya asignado como solo lectura.
- Mi perfil permite crear el usuario que falta, sin impedir editar perfiles anteriores.
  Rol, organizaciones, sedes, especialidades y estados se consultan sin conceder permisos.
- Avatar y fotografía siguen usando el editor y persistencia existentes.

añade datos sintéticos aislados por organización y contexto de sede.
